Demo limitations

  • Browser-only demo; data is stored only in this browser.
  • No production database or server-enforced security; demo authentication is browser-local.
  • GCash QR is mocked; proof images are browser-stored and still require manual verification.
  • Machine completion is manually marked.
  • No receipt printer, accounting or ESP32 integration yet.
  • Use fake customer data only.

Data Management

Upgrades preserve existing browser data. A pre-migration safety copy is kept locally before schema changes.
Backup format: JSON · schema v18 · payment proof images remain in browser storage
